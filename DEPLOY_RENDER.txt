BEST METHOD (persistent accounts, messages, comments and notifications):

1. Push this complete folder to GitHub.
2. In Render choose New + -> Blueprint.
3. Select your GitHub repository.
4. Render reads render.yaml and creates the app and PostgreSQL database.
5. Deploy it.

MANUAL WEB SERVICE METHOD:

Build Command:
pip install -r requirements.txt

Start Command:
python -m uvicorn app.main:app --host 0.0.0.0 --port $PORT

Required Environment Variables:
DATABASE_URL=<PostgreSQL or Supabase connection string>
SECRET_KEY=<long random secret; do not change after deployment>
ACCESS_TOKEN_DAYS=365

Never change SECRET_KEY after users have logged in. Changing it invalidates all saved login sessions.
Use PostgreSQL/Supabase online so accounts, messages, likes, comments and notifications survive restarts.
